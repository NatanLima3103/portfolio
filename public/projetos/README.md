# Imagens dos projetos

Coloque aqui os diagramas de arquitetura referenciados nos arquivos de
`src/content/projetos/`. Use PNG ou SVG e mantenha o nome que o `.md` espera:

- `certidoes.png`
- `monitor-processos.png`
- `triagem-intimacoes.png`
- `juridico-ai.png`

Depois de salvar a imagem, abra o `.md` correspondente e descomente a linha
`<!-- ![...](/projetos/arquivo.png) -->` da seção **Arquitetura**.

Dica: largura entre 1200px e 1600px é suficiente. Escreva um texto alternativo
descritivo entre os colchetes — é o que leitores de tela vão anunciar.
